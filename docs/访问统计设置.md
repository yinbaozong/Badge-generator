# 访问统计设置

网站使用 Cloudflare Web Analytics。站点仍托管于 GitHub Pages，不需要迁移域名。

1. 登录 https://dash.cloudflare.com/ ，进入 Web Analytics（网站分析）。
2. 点击 Add a site，输入主机名 `yinbaozong.github.io`，选择该主机名并确认。
3. 打开 Manage site，复制 JavaScript snippet。里面的 `token` 是公开的站点统计标识，不是账户 API 密钥。
4. 在 GitHub 仓库 Settings → Secrets and variables → Actions → Variables 中，添加 `CLOUDFLARE_ANALYTICS_TOKEN`，值填入统计代码中的 32 位 token。
5. 运行 GitHub Pages 发布流程。构建时会把统计脚本加入页面。没有 token 时不会加载统计脚本。
6. 访问一次正式网站，等待几分钟，然后在 Cloudflare Web Analytics 查看数据。按路径筛选 `/Badge-generator/`，以免与同一主机名下的其他网站混淆。

统计只能从启用后开始，无法补回之前的访问量。数据可能受浏览器拦截等因素影响，不能当作精确人数。图案上传、模型处理和导出仍在浏览器完成；本接入不发送上传文件、文件名或模型参数。

本地构建可在 `.env.local` 设置 `VITE_CLOUDFLARE_ANALYTICS_TOKEN=站点token`。开发模式不会加载统计脚本，发布构建会加载。

官方说明：https://developers.cloudflare.com/web-analytics/get-started/
