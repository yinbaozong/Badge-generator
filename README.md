# MakerWorld 参数化拼接徽章生成器

上传一个 SVG 图案，生成可以互相拼接的徽章。

- 外形：圆角矩形（默认正方形）、圆角六边形、拼图、Logo 外形
- 拼接：“拼图”外形带圆头拼图扣，宽高相同的拼图徽章可以直接拼在一起
- 磁铁：背面可选常见规格的磁铁槽
- 上色：底座和图案是两个独立实体，在 Bambu Studio 中分别指定耗材即可

## 文件

- `badge_generator.scad`：上传到 MakerWorld 的主文件
- `examples/sample-4color.svg`：本地测试用的 SVG 图案

## MakerWorld 使用流程

1. 在 MakerWorld 的 Creator Portal 选择 **Open SCAD File**，打开 `badge_generator.scad`。
2. 在第一项“图案文件”中上传自己的 SVG。
3. 选择外形、宽度、高度、厚度、圆角和图案留边。
4. 生成后下载 **3MF**，在 Bambu Studio 中给底座和图案分别选择耗材。

## 参数说明

MakerWorld 的参数面板不能根据某个选项隐藏其他参数。除“拼图间隙”只对拼图外形生效外，其他参数在所有外形下都有意义：

| 分组 | 参数 | 作用 |
| --- | --- | --- |
| 图案文件 | `svg_file` | 上传的 SVG 图案 |
| 徽章外形 | `badge_shape` | 圆角矩形、圆角六边形、拼图、Logo 外形 |
| 徽章外形 | `badge_width` | 徽章宽度；六边形为左右对角宽度，Logo 外形为图案可占用的最大宽度 |
| 徽章外形 | `badge_height` | 徽章高度；Logo 外形为图案可占用的最大高度 |
| 徽章外形 | `base_thickness` | 底座厚度；装磁铁时会自动加厚 |
| 徽章外形 | `corner_radius` | 矩形、六边形和拼图为转角圆角，Logo 外形为轮廓平滑度 |
| 图案 | `logo_margin` | 图案到徽章边缘的距离 |
| 图案 | `logo_height` | 图案凸起高度 |
| 磁铁 | `magnet_preset` | 磁铁规格和数量 |
| 拼图 | `puzzle_clearance` | 拼图扣单边间隙，默认 0.2 mm |

OpenSCAD 的参数变量名只能使用英文，所以参数的中文写在每项的小字说明和下拉选项中。

## 宽度和高度

- 默认宽高都是 `40 mm`，即正方形；分别修改宽度和高度就能得到长方形。
- 图案保持原始比例，在“宽度 − 2 × 图案留边”和“高度 − 2 × 图案留边”的范围内尽量放大并居中。
- 六边形也按宽高生成；正六边形的高度约为宽度的 `0.87` 倍，例如宽 40 时高度填 35。
- Logo 外形的宽高是图案可占用的最大范围，徽章轮廓跟随图案，再向外扩出图案留边。

## 拼图拼接

选择“拼图”外形后，徽章右边和上边是圆头凸扣，左边和下边是凹槽，宽高相同的拼图徽章可以上下左右任意拼接。

- 拼接时把一个徽章的凸扣从上往下压入另一个徽章的凹槽。
- 只有宽度和高度都相同的拼图徽章才能拼成完整网格。
- 图案会自动避开凹槽区域。
- 拼图扣大小随徽章尺寸按比例缩放。

`puzzle_clearance` 是单边间隙，默认 `0.2 mm`：

- 太紧：每次增加 `0.05 mm`
- 太松：每次减少 `0.05 mm`

## 磁铁槽

磁铁槽开在徽章背面，正面至少保留 `0.5 mm`。选择磁铁后，如果底座厚度不够，会自动加厚。

建议用少量胶水固定磁铁，并在装胶前确认所有徽章的磁极方向一致。

双磁铁沿宽度方向排列，四磁铁按宽高各取约 45% 的间距排列。Logo 外形的轮廓不规则，建议只使用“中心1个”磁铁槽，避免磁铁槽落到轮廓外面。

## SVG 要求

- 使用闭合的填充路径。
- 文字先转为路径，描边先转为填充路径。
- 不要使用位图、滤镜、蒙版和裁剪路径。
- 图案会自动居中，并保持比例缩放到可用范围内。

OpenSCAD 只能读取 SVG 的形状，读不到 SVG 原本的填充颜色。所以生成器输出的是“底座 + 图案”两个实体。如果图案本身需要多种颜色，请在 Bambu Studio 中：

- 对图案执行“拆分为零件”，再给不相连的部分分别指定耗材；
- 或使用涂色工具，给需要的区域上色。

## 本地测试

将测试图案复制为 `default.svg` 后运行：

```powershell
Copy-Item examples\sample-4color.svg default.svg
openscad -o badge-test.3mf badge_generator.scad
```
