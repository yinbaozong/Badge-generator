# 徽章生成器

[在线使用](https://yinbaozong.github.io/badge-generator/) · [English guide](docs/README.en.md) · [反馈问题](https://github.com/yinbaozong/badge-generator/issues)

上传一张图，调好尺寸，就可以下载打印用的徽章。支持 SVG，也可以试试 PNG / JPG。图片处理和模型生成都在浏览器里完成，不会上传你的文件。

![Claude Code、Codex、OpenAI、Apple、Python 等图案的三种徽章外形](docs/images/brand-showcase.png)

这张图用了 8 个 SVG，分别生成矩形、六边形和 Logo 外形，共 24 个示例。是生成模型的渲染图，不是品牌合作或打印认证。

## 怎么用

1. **上传图案。** SVG 用蓝色“上传 SVG”按钮；PNG / JPG 用下面的实验入口。也可以先点“使用示例”熟悉一下。
2. **选单色或多色。** 单色是白底黑图；多色保留图案的实色。渐变会取代表色，不会保留连续渐变。
3. **调整尺寸。** 左边点“尺寸”，选外形，再设置宽度、留边、底壳厚度和 Logo 厚度。模型会自动更新。
4. **需要磁铁就选位置。** 点“磁铁”，启用磁铁槽，填直径和厚度，再点“在背面选点”。
5. **下载模型。** 顶部可以下载 STL、彩色 3MF 或 SCAD。多色打印建议下载 3MF，用 Bambu Studio 打开后选择实际使用的耗材。

标题旁的 EN / 中文开关可以切换语言。首次打开默认英文，之后记住你的选择。

## 单色和多色

| 单色 | 多色 |
| --- | --- |
| ![白底黑图徽章](docs/images/single-color.png) | ![保留色块的多色徽章](docs/images/multicolor.png) |
| 白色底壳，黑色凸起。原图里独立的白色文字也会转成黑色；覆盖在彩色图案上的白色路径通常作为留白。 | 保留实色色块，不同颜色自动错开 0.2 mm 高度，方便在切片软件里上色。 |

STL 不带颜色；3MF 带颜色和部件。3MF 里的颜色不会自动对应你的 AMS 槽位，打开后仍要选耗材。

## 四种外形

**圆角矩形**是默认外形。宽度和长度可以分别调整，圆角设为 0 就是直角矩形。上面的示例使用 40 × 40 mm 底壳。

| 正六边形 | Logo 外形 |
| --- | --- |
| ![正六边形徽章](docs/images/hexagon.png) | ![沿图案轮廓生成的徽章](docs/images/logo-outline.png) |
| 六边等长，长度由宽度自动计算。圆角可以自行调整；图里是圆角为 0 的效果。 | 底壳沿图案轮廓留边，并稍微平滑尖角。宽度可调，长度按原图比例自动计算。 |

**拼图外形**可以把尺寸相同的徽章拼在一起。默认间隙为 0.2 mm；打印后太紧就调大一点，太松就调小一点。宽度和长度都要至少 25 mm。

![带拼接扣的拼图徽章](docs/images/puzzle.png)

Logo 外形可能会出现分离的底壳，例如字母和下方箭头各自成一块。如果希望它们连起来，可以增大留边，或者改用矩形。

## 尺寸怎么看

- **宽度 X / 长度 Y**：底壳平面尺寸。Logo 外形和正六边形的 Y 自动计算。
- **底壳厚度 Z**：下面底壳的厚度，可设为 1.5–20 mm。
- **Logo 厚度 Z**：上面图案的基础凸起厚度，可设为 0.2–20 mm。多色模式另有 0.2 mm 色区台阶。
- **留边**：图案周围留多少底壳。

右下角显示生成后的实际 X / Y / Z，总高度包含底壳和图案。改宽度不会改变厚度。参数不合适时，错误会显示在预览上方；此时预览可能保留上一次的模型，修正后才能下载。

六边形的留边按真实边界计算，图案等比放大到能完整放进内边界的尺寸。1 mm 指最小间距，不是图案四周每处空白都一样大。

## 只要 Logo，不要底壳

在“尺寸”里勾选“仅 Logo，不带底壳”。预览和 STL / 3MF / SCAD 导出都只包含图案，宽度按 Logo 本身计算，厚度仍由 Logo 厚度控制。外形、留边、底壳厚度和磁铁槽会停用。

没有底壳帮忙连接，字母、圆点或其他分离的部分会各自独立。打印和摆放时要注意这一点。

## 磁铁槽

![底壳背面的两个磁铁凹槽](docs/images/magnets.png)

磁铁不用放在中心。启用后点“在背面选点”，在底壳上点击放置，最多 8 个。位置有编号，可以逐个删除重选，最后点“完成选点”。

直径会自动多留 0.3 mm，深度多留 0.1 mm。槽与边缘、槽与槽之间至少留 0.5 mm；位置放不下时会提示对应编号。如果底壳太薄，工具会自动加厚并提示你。分离的底壳可以各自放磁铁。

## 保存常用模板

左下角的“导出配置”保存尺寸、外形、颜色模式、是否需要底壳和磁铁位置。下次上传新图，再点“导入配置”，就不用重新填参数了。

模板不包含图案文件。磁铁位置按底壳比例保存，换图后记得检查有没有落在空白或太窄的地方。

## PNG / JPG 效果不理想怎么办

这个入口适合清晰图标、透明背景或纯色背景图片，还属于实验功能。照片会简化为最多 6 种颜色。自动去背景有时会误删浅色细节，可以关掉再试。

小图、截图里的文字放大后仍可能有轻微锯齿。工具会平滑轮廓、清理边缘杂色，但补不回原图丢失的细节。如果结果不好，建议找原始 SVG，或用 [PNG to SVG](https://pngtosvg.com/) 转换后再上传。这个链接是独立的外部工具，本项目不会自动向它发送文件。

SVG 请尽量使用闭合的填色路径。文字和描边先转路径；暂不支持蒙版、滤镜、嵌入图片等内容。

## 去哪里找 SVG

- [theSVG](https://thesvg.org/)：找品牌 Logo 可以从这里开始。
- [SVGL](https://svgl.app/)：有许多软件、开发工具和 AI 品牌的 SVG。
- [Simple Icons](https://simpleicons.org/)：找单色品牌图标时很方便。

下载后用“上传 SVG”导入。不同文件的结构不一样，遇到文字、描边或蒙版提示时，需要先转为普通填色路径。品牌图案的使用范围请以各品牌要求为准；本项目的 MIT 许可不代表品牌标识也属于 MIT。
